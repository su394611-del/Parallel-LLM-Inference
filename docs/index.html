Parallel LLM Inference with PyTorch

An educational AI engineering project demonstrating parallel batch inference, multi-process worker orchestration, and sentiment classification using Qwen2.5.

Project Features

  • Parallel LLM batch inference
  • Qwen2.5-0.5B-Instruct model
  • PyTorch and Hugging Face Transformers
  • Python multiprocessing worker pool
  • Single-GPU and multi-GPU inference
  • Independent model replica per GPU
  • Shared task queue and result queue
  • Dynamic mini-batch processing
  • Length-sorted batches to reduce padding
  • Input and output JSONL validation
  • Product review sentiment classification
  • Stable output ordering
  • Inference performance measurements
  • Offline mock testing with CPU workers
  • Jupyter, Colab and Kaggle examples

System Architecture

Input JSONL records are validated by a parent process and distributed through a shared task queue to independent inference workers. Each worker processes batches using its assigned device. Results return to the parent process, which restores original input order.

Multi-GPU Inference

Each GPU loads a separate complete model replica. This is data-parallel inference, not DistributedDataParallel training or tensor/model parallelism. GPU memory is not combined across devices.

Qwen2.5 Sentiment Classification

The project demonstrates product-review sentiment classification using Qwen2.5-0.5B-Instruct with configurable batch sizes, input token limits and output generation settings.

Testing and Limitations

Offline mock testing validates queue processing and file handling without running an LLM. Real inference requires compatible hardware and model weights. Performance improvements are not guaranteed.
